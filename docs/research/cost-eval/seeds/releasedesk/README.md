# Seed: ReleaseDesk

The second seed: an archive's publication service, where embargoes, approvals, and takedowns decide what the public can see, and every new surface (search, bundles, previews, manifests) must respect the same rules. GPT-6.1 Sol proposed it ([seed-proposals/gpt-6.1-sol.md](../../seed-proposals/gpt-6.1-sol.md)).

**Status:** being designed. The first seed showed that a strong model guesses most intent that is a sensible default (see [log.md](../../log.md), 2026-11-14). ReleaseDesk is meant to also carry intent a strong model wouldn't guess, which real owners set either way, and which later changes have to keep respecting. Ideas come first from several model families, starting with Gemini 4 Carbon and Claude Fable, working independently from [prompts/01-surprising-intent.md](prompts/01-surprising-intent.md).

- **Public:** this README and the authoring prompts in [prompts/](prompts/).
- **Private, in `hidden/`:** each model's ideas, and later the oracle, change script, probes, and edit log, until the runs that use them finish.
