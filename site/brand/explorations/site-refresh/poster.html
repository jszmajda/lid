How do you know your agent built what you meant?

  • Because you wrote it down: a design, in plain English.
  • Because everything the agent builds comes from that design.
  • Because you can check: one ID grep returns the requirement, its tests, and its code.
  • Because LID helped you get there.

Design first. Everything below it cites an ID.

Code that runs can still miss what you meant. With LID, the design stays linked to everything built from it: fix it once, the agent cascades the change, and you sign off or push back at every step.

Every code file cites, by ID, the spec it implements. Every test cites the spec it asserts, and every spec traces to a design.

HLDthe why
The app is account-scoped. Only the account owner can see or change their data, so every request has to identify the caller.
LLDthe how
Credentials enter at the login form, pass to the auth service, and resolve to a session scoped to the user or a structured AuthError.
EARSthe claim
AUTH-UI-001 When a user submits valid credentials, the authentication service shall return a session scoped to that user.
Testsfailing first
test("returns a session on valid credentials")
  ▸ AUTH-UI-001
Code@spec anchors
// services/auth.ts
// @spec AUTH-UI-001, AUTH-UI-002
async function authenticate(credentials) { … }

A spec ID is a grep target. grep -r AUTH-UI-001 returns the spec, the tests that assert it, and the code that implements it.

Watch one edit reach the code.

Change one sentence of the design and watch it arrive in the specs, the tests, and the code. Two minutes, one real project.

Four commands, inside Claude Code.

Install the two plugins, then describe what you want to build. The skill walks you through design, specs, and tests before it writes any code.

  1. /plugin marketplace add jszmajda/lidRegister the plugin source in Claude Code.
  2. /plugin install linked-intent-dev@jszmajda-lidInstall the core workflow plugin.
  3. /plugin install arrow-maintenance@jszmajda-lidTrack the links between specs and code in big projects.
  4. /linked-intent-devDescribe what you want to build.

Using a different coding agent? Most tools need only an AGENTS.md at your project root. Setup for Cursor, Windsurf, GitHub Copilot, Aider, and every other tool.
