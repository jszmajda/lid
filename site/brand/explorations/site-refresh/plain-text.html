MKT-SITE-001

# How do you know your agent built what you meant?

  1. Because you wrote it down: a design, in plain English.
  2. Because everything the agent builds comes from that design.
  3. Because you can check: one ID grep returns the requirement, its tests, and its code.
  4. Because LID helped you get there.

Code that runs can still miss what you meant. With LID (Linked-Intent Development), the design stays linked to everything built from it. Fix it once, the agent cascades the change, and you sign off or push back at every step.

MKT-SITE-038

## Design first. Everything below it cites an ID.

Every code file cites, by ID, the spec it implements. Every test cites the spec it asserts, and every spec traces to a design. Checking that code still traces to design is a walk through that graph, mechanical enough to put in CI.

  1. docs/high-level-design.md # the why

    The app is account-scoped. Only the account owner can see or change their data, so every request has to identify the caller.

    1. docs/intent/auth/auth-design.md # the how

      Credentials enter at the login form, pass to the auth service, and resolve to a session scoped to the user or a structured AuthError.

      1. docs/intent/auth/auth-specs.md # the claim

        AUTH-UI-001 When a user submits valid credentials, the authentication service shall return a session scoped to that user.

        1. tests/auth.test.ts # failing first
          test("returns a session on valid credentials") // AUTH-UI-001
        2. src/services/auth.ts # @spec anchors
          // @spec AUTH-UI-001, AUTH-UI-002
async function authenticate(credentials) { … }

MKT-SITE-006

## Four commands, inside Claude Code.

Install the two plugins, then describe what you want to build. The skill walks you through design, specs, and tests before it writes any code.

  1. # Register the plugin source in Claude Code./plugin marketplace add jszmajda/lid
  2. # Install the core workflow plugin./plugin install linked-intent-dev@jszmajda-lid
  3. # Track the links between specs and code in big projects./plugin install arrow-maintenance@jszmajda-lid
  4. # Describe what you want to build./linked-intent-dev

Using a different coding agent? Most tools need only an AGENTS.md at your project root. Setup for Cursor, Windsurf, GitHub Copilot, Codex CLI, Aider, Zed, and every other tool.
