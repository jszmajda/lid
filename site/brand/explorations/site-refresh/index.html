Five directions for the LID site

Each one is the home page with its real copy: the hero, the traced example, the demo, the quickstart, and the four paths. Palette A stays on the logo in all five; they differ in how much orange reaches the rest of the page. Every page works in light and dark, and the bar at the bottom switches pages and themes.

  1. ALinked list

    Every section is a node that points to the next one, the way the logo points from L to I to D. The hero draws HLD, LLD, EARS, Tests, and Code as five logo tiles joined by the logo's pointer. The closest match to the logo itself.

    Type
    Geologica, with Spline Sans Mono for code
    Orange
    The logo, plus the small pointers between nodes
    Logo
    The wordmark on its orange ground in the nav; the L icon in the footer
    Open Linked list
  2. BPlain text

    The page is set like a spec file. The margin shows the ID of the site spec each section implements, and each ID links to it. Headings keep their markdown marks, and the hero's picture is a grep that returns a requirement, its test, and its code. The quietest of the five.

    Type
    Martian Mono for headings and code, Newsreader for prose
    Orange
    The icon, and the highlight on each grep match
    Logo
    The flush-cut L icon leads the nav, with the domain beside it
    Open Plain text
  3. CStickers

    The logo keeps palette A, and each section of the page takes one of the logo's other palettes, B through G. The wordmark and the flush-cut icon show up as die-cut stickers, and the path cards are stickers too. The most playful and the most colorful.

    Type
    Recursive: casual for headings, linear for text, mono for code
    Orange
    Only the logo stickers and the play button
    Logo
    A wordmark sticker in the nav; a sheet of stickers in the hero
    Open Stickers
  4. DPoster

    Loud once. A full-width orange band carries the wordmark at poster size and the headline in wide type. Below it, the page is black and white on a strict grid with heavy rules. This one tests how much orange the site can take if it all sits in one place.

    Type
    Archivo, wide for headings and regular for text, with Azeret Mono for code
    Orange
    The whole hero band, and nothing else
    Logo
    The tiles alone, as wide as the page, on the band's orange
    Open Poster
  5. ERail

    Dark first, in warm browns taken from the logo's ink. One rail runs down the page like git log --graph, with each section as a node on it. The hero shows one design edit cascading through specs, tests, and code as a graph log. The closest to the current site's dark default.

    Type
    Atkinson Hyperlegible Next and Atkinson Hyperlegible Mono
    Orange
    The logo; the page uses a softer apricot, with mint for spec IDs
    Logo
    The wordmark on its orange ground in the nav
    Open Rail

The mocks leave out the Teams, Experimental, and Ecosystem sections and the How it works graph. Fonts come from Google Fonts here; the live site would load the same families from Bunny Fonts.
